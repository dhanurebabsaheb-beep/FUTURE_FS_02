# Client Lead Management System (Mini CRM)

A simple CRM application to manage client leads generated from website contact forms.

## Features

- Admin Login
- Add new leads
- View leads
- Update lead status
- Search leads
- Delete leads
- Follow-up date
- Notes
- Dashboard with lead counts

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
